# Diana Rose Angan-angan — Portfolio

My personal developer portfolio, live at **[dianaangan.github.io/github-portfolio](https://dianaangan.github.io/github-portfolio)**.

Built with React, Vite, Tailwind CSS, and Framer Motion.

## Running locally

```bash
npm install
npm run dev
```

## Deployment

Pushing to `main` auto-deploys to GitHub Pages via the workflow in `.github/workflows/deploy.yml`.
